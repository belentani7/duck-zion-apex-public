# Fuentes oficiales del catálogo de diez plugins

| Plugin                        | Fuente oficial                                               | Evidencia funcional                                                                                  |
| ----------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| MAutoPitch                    | https://www.meldaproduction.com/MAutoPitch                   | Afinación vocal, corrección de tono, formantes y expansión estéreo; freeware según el fabricante.    |
| TDR Nova                      | https://www.tokyodawn.net/tdr-nova/                          | EQ paramétrico y dinámico, compresión selectiva, filtros HP/LP y soporte VST3.                       |
| T-De-Esser 2                  | https://techivation.com/t-de-esser/                          | Control de sibilancia y aspereza; Windows 64-bit VST/VST3/AAX. No se redistribuyen sus instaladores. |
| DC1A                          | https://klanghelm.com/contents/products/DC1A.html            | Compresión de carácter, paralela, peak/RMS y freeware.                                               |
| IVGI2                         | https://klanghelm.com/contents/products/IVGI.html            | Saturación armónica freeware para voz, buses y master.                                               |
| Valhalla Supermassive         | https://valhalladsp.com/shop/reverb/valhalla-supermassive/   | Delay/reverb gratuito con modos para ecos, espacios y transiciones.                                  |
| Youlean Loudness Meter 2 Free | https://youlean.co/youlean-loudness-meter/                   | Medición LU, LUFS, true peak, LRA, PLR y dinámica; incluye formatos para DAW y Windows.              |
| Surge XT                      | https://surge-synthesizer.github.io/                         | Sintetizador híbrido de código abierto con VST3/CLAP/standalone para Windows.                        |
| Decent Sampler                | https://www.decentsamples.com/product/decent-sampler-plugin/ | Sampler gratuito disponible como VST/VST3/AAX/standalone en Windows.                                 |
| Limiter No6                   | https://github.com/losno/limiter6                            | Candidato de limitación final; la build y licencia deben verificarse antes de distribución.          |

El proyecto solo muestra enlaces y guías. No instala ni descarga plugins de terceros silenciosamente. La verificación de estado permanece `pending` hasta revisar hash, firma, arquitectura, licencia y carga real en FL Studio.
